## Slice 4 — Admin: hide spam, rename places ✅

Wallie's choices (2026-10-09): an **admin key**, hiding **a single entry** or **everything from one device**, **hidden and restorable** (not deleted). A device is the per-device `ReporterKey` every event and spot already carries (`KingEvent.cs`, `Spot.cs`); it is never returned by the API — admin endpoints don't return it either, only an opaque id for the hidden-device record. Hiding is by device, so that device's *later* posts are hidden too until restored. No new dependencies.
