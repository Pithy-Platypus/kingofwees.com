# Slice 4b — Posting only from the US ✅

_Moved from `PLAN.md` on 2026-10-24, as it stood._

Wallie's request (2026-10-11): "I saw King" and "I fed King" work only for visitors in the US; others see a message. Recommendation given first (wait for spam; posting only, not `/admin`; honest wording, since a US address isn't "local" and a VPN gets around it) — Wallie chose to build it, posting only. Checked before building: **DB-IP IP-to-Country Lite** is CC BY 4.0 (redistribution allowed with the link "IP Geolocation by DB-IP" on pages that use it), monthly, 8.3 MB `.mmdb` with MaxMind's layout (`country.iso_code`; its metadata says `DBIP-Country-Lite`, so no database-type check); read with **MaxMind.Db 5.2.0** (Apache-2.0, no dependencies, net10.0) — the new dependency, chosen over writing an MMDB reader. Queried both the real October file (8.8.8.8 → US, 81.2.69.160 → GB, private → none) and MaxMind's 19 KB test database (Apache-2.0/MIT; 216.160.83.56 → US, 81.2.69.160 → GB, 1.1.1.1 → none), which the tests use. Not chosen: Cloudflare's country header (needs its proxy, which breaks ACA's managed certificate), Front Door's geo-filter ($35+/month), MaxMind GeoLite2 (its licence doesn't allow shipping it in our public image).
