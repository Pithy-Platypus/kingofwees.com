# Slice 5 — Go live on Azure Container Apps ✅

_Moved from `PLAN.md` on 2026-10-24, as it stood._

Wallie's choices (2026-10-09): **Azure Container Apps** (ACA, Consumption plan), **one replica, always warm** (no cold starts), budget **under $25/month** (estimate ~$7–13, measured in step 1 at ~$6–7: app ~$6 at 0.25 vCPU / 0.5 GiB, mostly at the idle rate, database $0, backups cents). **Azure DocumentDB free tier** (MongoDB API, 32 GB, US region) as the production database — a Mongo container can't run on ACA (its network file shares corrupt Mongo's data directory). **Cloudflare stays** registrar and DNS, records **DNS only** (grey cloud): ACA's free managed certificate can't be issued or renewed behind Cloudflare's proxy. **Kestrel** serves the app. Images on **GitHub Container Registry** (public repo → public images, no secrets inside), deployed by a **script from Wallie's Mac**. Rejected, with costs: one VM (B1ms, ~$22/month, OS patching, firewall, certificate), Azure DNS (Cloudflare Registrar domains must keep Cloudflare's nameservers), Azure Front Door ($35+/month), Let's Encrypt in Kestrel (renewals ours; LettuceEncrypt is archived). **Fallback if step 2 fails:** one Azure VM via Compose with Cloudflare proxy + origin certificate in Kestrel, port 443 open only to Cloudflare's ranges.
